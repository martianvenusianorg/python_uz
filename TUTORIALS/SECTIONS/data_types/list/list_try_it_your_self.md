## **Topshiriqlar:**

**1-topshiriq:**

O'zida do'stlaringizning ismlarini saqlovchi list yarating. Listing har bir elementiga murojaat qilgan holda ro'yxatdagi ismlarni ketma-ket chop eting.

Natija quyidagi ko'rinishda chop etilishi kutiladi:

```
akbar
akrom
humoyiddin
dilmurod
elmurod
```

elmurod


**2-topshiriq:**

1-mashqda yaratilgan list dan foydalanib, har bir do'stingizning ismini chop etish vaqtida ularning ismlarining oldida yangi xabarni birgalikda chop eting. Biroq agar ro'yxatingizdagi ismlar kichik harflar bilan boshlansa ismlarni katta xarf bilan chop eting. Aytaylik ro'yxatdagi do'stlaringizdan biri "akrom" va birga chop etiladigan xabar "Hello" so'zidan iborat bo'lsa unda chop etiladigan gap "Salom Akrom" shaklida bo'lishi kerak.

Natija quydagi ko'rinishda chop etilishi kutiladi:

```
Hello Akbar
Hello Akrom
Hello Humoyiddin
Hello Dilmurod
Hello Elmurod
```



**3-topshiriq:**

Python yoki C++ kabi sevimli dasturlash tillariniringizni o'zida saqlovchi list yarating. Ro'yxatingizdagi xar bir dasturlash tilidan foydalanib “Men Python dasturlash tilini o'rganishni xohlayman” kabi gaplarni chop eting.

Natija quydagi ko'rinishda chop etilishi kutiladi:

```
I would like to learn Python programming language
I would like to learn C++ programming language
I would like to learn C programming language
I would like to learn Javascript programming language
I would like to learn Go programming language
I would like to learn Swift programming language
```
